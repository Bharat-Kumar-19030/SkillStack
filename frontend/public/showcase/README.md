# Profile Showcase Images

This directory contains sample profile screenshots displayed in the landing page carousel.

## Required Images

Please add the following images to this directory:

1. **leetcode-profile.png** - Screenshot of LeetCode profile with stats
2. **projects-section.png** - Screenshot of projects display section
3. **github-stats.png** - Screenshot of GitHub analytics/stats (optional)

## Image Specifications

- **Format**: PNG or JPG
- **Recommended Size**: 1920x1080px or similar 16:9 aspect ratio
- **File Size**: Keep under 500KB for fast loading

## How to Add Images

1. Save your screenshots with the exact names above
2. Place them in this `/public/showcase/` directory
3. The carousel will automatically display them on the landing page
